# Internationalization (i18n)

- Languages: English, Spanish, French (extensible).
- Default for new users: **Spanish**.
- Preference in `localStorage`; applied on load.
- Translate UI only (labels, buttons, nav, system messages). Never translate user content (meals, ingredients, household names).
- Language picker lives in the profile dropdown (inline expand between dark mode and settings).
- Locale files: `src/locales/{en,es,fr}.json` — keys by domain (`nav.*`, `meals.*`, etc.).
