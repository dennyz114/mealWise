# Application layout

- Global breakpoint: **640px** (mobile vs desktop).
- **Header** (always): logo + avatar; avatar opens profile dropdown.
- **Mobile**: fixed bottom tabs — Meals, Planner, Shopping.
- **Desktop**: left sidebar (collapsed icon-only / expanded with labels); preference persisted.
- Profile dropdown: user info, household / join code + copy, dark mode, language, settings, sign out.
- Primary routes: `/meals`, planner, shopping.
