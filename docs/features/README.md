# Feature guidance (session reference)

**Purpose:** Lightweight product/UX guidance for AI sessions and development.  
When changing a feature, **read the matching file here** (and `docs/DATABASE.md` when relevant) instead of pasting long context.

**How we work going forward**
- New or updated feature rules go in `docs/features/<name>.md` (short bullets, not ticket ceremony).
- Keep files scannable. Deep schema → `docs/DATABASE.md`.
- Optional mockups → `docs/features/assets/`.
